# Local DOOM wrapper assets

`js-dos-api.js` and `js-dos-v3.js` are local copies from
[`thedoggybrad/doom_on_js-dos`](https://github.com/thedoggybrad/doom_on_js-dos),
with the runtime URL in `js-dos-api.js` changed to this directory. The upstream
repository is MIT-licensed; its licence is preserved in
`THIRD_PARTY_LICENSE.txt`.

The DOOM game archive is not included or redistributed. The launcher continues
to request it from the upstream project at runtime.
