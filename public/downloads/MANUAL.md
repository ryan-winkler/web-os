# DOOM on JS-DOS User Manual

This local copy keeps the controls available when the upstream GitHub page is not.

[Open the game](https://thedoggybrad.github.io/doom_on_js-dos/)

## Start the game

1. Select **Click to start** and wait for the game to load.
2. Press any movement key after loading.
3. Use the movement keys to navigate the game menu.
4. Enjoy.

## Game controls

| Action | Key |
| --- | --- |
| Move | Up, Down, Left, Right |
| Use | W |
| Fire | S |
| Speed | Space |
| Strafe mode | Alt |
| Strafe | A, D |
| Change weapon | 1, 2, 3, 4, 5, 6, 7 |
